# Verhaltenskodex

## Unser Anspruch

Wir wollen eine sachliche, respektvolle und diskriminierungsfreie Zusammenarbeit
ermöglichen – unabhängig von Erfahrungsstand, Herkunft, Geschlecht, Identität,
Religion, Behinderung oder Alter.

## Erwartetes Verhalten

- konstruktive und konkrete Kritik, bezogen auf Code und Sache
- Geduld mit weniger erfahrenen Beitragenden
- Anerkennung unterschiedlicher Meinungen und Lösungswege
- Verantwortung für eigene Fehler und Bereitschaft zur Korrektur

## Nicht akzeptiert

- Beleidigungen, Herabsetzungen, persönliche Angriffe
- sexistische, rassistische, homophobe, transfeindliche oder ableistische Äußerungen
- Belästigung jeder Art, auch in privaten Nachrichten
- Veröffentlichung privater Informationen anderer ohne Zustimmung
- wiederholtes Stören von Diskussionen

## Geltungsbereich

Der Kodex gilt für alle Projektbereiche (Issues, Pull Requests, Diskussionen)
sowie für Auftritte, in denen das Projekt vertreten wird.

## Durchsetzung

Verstöße können an die Projektverantwortlichen gemeldet werden – über eine
private Nachricht an den Maintainer im GitHub-Profil oder per
GitHub Security Advisory, wenn Vertraulichkeit erforderlich ist. Meldungen
werden vertraulich behandelt.

Mögliche Maßnahmen: Hinweis, Verwarnung, Entfernung von Beiträgen, temporärer
oder dauerhafter Ausschluss.
